# コエシル(歌声診断アプリ)

K's VOX の無料アプリ。ドレミのスケールを歌うだけで、声を解析し、7つのボイスタイプに分類、練習のアドバイスとK's VOXのオリジナル英語曲を提案します。

- 録音と解析はすべてブラウザの中で行い、声はどこにも送信・保存しません(AIは使っていません)
- おすすめ曲は門弟アプリのFirebase(songs)をサーバー側から読み込みます

## デプロイナウの環境変数
- FIREBASE_CLIENT_EMAIL(門弟アプリと同じ値)
- FIREBASE_PRIVATE_KEY(門弟アプリと同じ値)

## 調整する場所
- 測定のものさし: `lib/config.js` の `TUNE`
- タイプの判定プロフィール: `lib/types.js`
- 文章(先生の表から作成): `lib/content.json`
- 測定の詳細を見る: アドレスの最後に `?debug=1` をつけて診断すると、結果の一番下に数値が出ます
